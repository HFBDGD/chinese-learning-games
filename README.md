# 中文學習樂園

一個適合兩位小朋友共用裝置嘅繁體中文學習入口。

## 功能

- 大圖示、繁體中文介面，適合平板電腦操作
- 哥哥同細佬使用獨立學習檔案
- 聽音認字、閱讀理解、重組句子及寫字練習
- 每款遊戲分開記錄錯題，答啱後會移出錯題簿
- 家長專區可以查看紀錄、清除錯題或重設指定遊戲
- 所有進度只使用瀏覽器 `localStorage` 儲存在目前裝置

## 使用方法

直接開啟網站，先選擇哥哥或細佬，再選擇遊戲。長按右上角「家長」兩秒，可以開啟家長專區。使用鍵盤時，聚焦「家長」按鈕後按 Enter 亦可以開啟。

## 私隱及安全

網站係純靜態網頁，冇後端、冇分析工具、冇 API 金鑰，亦唔會將學習紀錄上傳到網絡。清除瀏覽器網站資料會一併清除本機進度。

## 部署

網站使用 GitHub Pages，由 `main` 分支根目錄提供 `index.html`。
