本遊戲參考你提供嘅小一繁體中文練習相，收錄課本例題及使用相關詞語編寫、經人手檢查嘅新句子。呢批資料未確認係學校正式考試嘅完整詞庫；你日後可以用考試範圍再更新。

iPad 特別注意：直接喺「檔案」App 預覽 HTML 只會睇到靜態畫面，唔會玩到。要透過 Safari 開啟由網頁伺服器提供嘅地址。發佈後直接用 Safari 開啟遊戲網址；亦可以由分享選單加入主畫面。

撳字卡會讀詞語；「基礎練習」亦會講簡單意思。長按後將字卡拖去答案行；已排好嘅字卡亦可以長按重新調位，或者拖返上去。放滿後撳「檢查答案」，每題都會用語音講解句子各部分點樣連起嚟，唔論答啱定答錯，亦可以慢速重聽。題庫目前只收錄部分已核對嘅其他排法；遇到合理答案未被接受，請家長協助核對。如果唔識做，可以隨時撳「睇答案，再下一題」；系統會先用語音示範答案，之後先可以轉下一題。

語音係透過 Safari 的內置語音功能，無需網絡服務或 API Key。必須有廣東話聲線先可以確保係粵語發音。如果「試聽」讀成普通話、冇聲或冇廣東話聲線，請到 iPad「設定 → 輔助使用 → 朗讀內容／朗讀與語音 → 聲音」，檢查有冇中文（香港）聲線；不同 iPadOS 版本名稱可能唔同。首次朗讀通常要先輕按畫面授權。建議開啟音量，同埋唔好用靜音模式。

練習成績只儲存喺目前瀏覽器的本機儲存空間；清除 Safari 網站資料可能會遺失進度。冇廣告、登入、上傳答案或者第三方追蹤。
